# 🛡️ DefenseAI

## AI-Assisted Interview Security & Decision-Support Platform

DefenseAI is an AI-assisted interview security and decision-support platform designed to help recruiters analyze candidate interviews using **Generative AI, computer-vision telemetry, and explainable risk assessment**.

The platform combines candidate information, interview responses, available camera signals, Gemini-based analysis, and a deterministic risk engine into a structured workflow for **human review**.

> **DefenseAI is a decision-support system, not an automated cheating detector or hiring decision-maker.**

## 🎯 Problem

Remote and AI-assisted interviews create challenges for recruiters when evaluating:

- Candidate responses
- Technical depth
- Resume-to-answer consistency
- Answer relevance
- Interview behavior and observable signals
- Potential inconsistencies during an interview

Recruiters often need to review multiple sources of information before making an informed decision.

DefenseAI brings these signals together into a single recruiter-focused platform.
